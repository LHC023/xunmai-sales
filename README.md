# 寻脉 · AI 找矿勘查智能体

不承诺见矿，只交付证据和概率，以及下一步该花的钱。

面向地质勘查的智能体，按"三位一体"（成矿地质体 / 成矿构造与成矿结构面 / 成矿作用特征标志）框架做预勘查研判：区分有矿异常与无矿异常、圈定靶区并排序（Ⅰ/Ⅱ/Ⅲ）、给出概率区间与下一步验证方案。

## 安装

1. 解压；
2. 将 `AGENT.md` 作为系统提示词导入你的智能体；
3. 未授权可直接做 1 次《精简研判》（不含靶区坐标、JSON 输出、盲测复盘）；
4. 需要完整功能时，按包内 `payment/README.md` 付款并联系发行方换取授权码，交给智能体本地验签即可解锁。
