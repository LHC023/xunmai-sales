## 三条判读纪律

1. 圈定"成矿有利空间 + 见矿概率"，不是矿体边界。
2. 资源量分阶段授权，预查阶段不出任何资源量数字。
3. 不确定就说不确定，灰区强制人工复核。

## 与普通 AI 找矿问答的区别

- 输出概率区间与不确定度，不给单一预测值；
- 每条结论可追溯到原始资料，全链路带 `run_id / data_version / kg_version / model_version / params_hash`；
- 明确区分"成矿有利"与"存在工业矿体"，也区分"地质潜力"与"经济可采潜力"；
- 主动指出假异常来源，而不是把异常越叠越像矿；
- 用 VOI 判断下一步工作值不值得做，而不是只给建议清单；
- 复核专家只能加证据/否证据/调权重/标缺口，不能直接改结论。
