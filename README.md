# 寻脉 · AI 找矿勘查智能体 v1.3.0

**地象几何 GeoMindra** · 2026-10-31

> 不承诺见矿，只交付证据和概率，以及下一步该花的钱。

## 这是什么

一套可移植的**六智能体集群**定义包：系统提示词、判读纪律、领域知识卡、输出契约、报告模板、Agent 交接协议，以及配套的架构与商业化方案。
**不含任何矿区实测数据，不含模型权重，不含第三方专有资料。**

## 付费使用流程

1. 未授权用户：1 次精简研判。
2. 扫描 `payment/qr.png`（微信）或 `payment/alipay-qr.jpg`（支付宝）付款（或经平台购买）。
3. 发行方签发授权码：`python _issuer/issue.py --tier personal --serial XM-0001 --days 365`。
4. 用户提交授权码，智能体调用 `license/verify.py` 验签，通过即解锁。
5. 解锁范围按档位：个人版含 01/02/03/05（报告与 2D 图件）；团队版另含 04/06 与 05 的 3D、GIS、双语交付。

> 注意：私钥与签发脚本位于分发目录之外的 `_issuer/`，**不要打包分发**。
> 包内门控是商务约束，不构成密码学级别的复制保护——真正的强制只能靠平台分发或服务端推理。

## 三条判读纪律

1. 圈定"成矿有利空间 + 见矿概率"，不是矿体边界。
2. 资源量分阶段授权，预查阶段不出任何资源量数字。
3. 不确定就说不确定，灰区强制人工复核。

## 与普通 AI 找矿问答的区别

- 输出概率区间与不确定度，不给单一预测值；
- 每条结论可追溯到原始资料，全链路带 `run_id / data_version / kg_version / model_version / params_hash`；
- 明确区分"成矿有利"与"存在工业矿体"，也区分"地质潜力"与"经济可采潜力"；
- 主动指出假异常来源，而不是把异常越叠越像矿；
- 用 VOI 判断下一步工作值不值得做，而不是只给建议清单；
- 六智能体按契约交接，上游缺证据时下游**拒绝执行**，而不是硬补；
- 复核专家只能加证据/否证据/调权重/标缺口，不能直接改结论。
